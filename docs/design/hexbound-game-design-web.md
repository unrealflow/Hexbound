## 1. 游戏定位

**一句话**：文明的地图骨架 + 英雄无敌的探索循环 + 博德之门 3 的战斗深度。

类比 Dota 之于魔兽争霸 3：本作**砍掉文明的建造、科技、城市、外交，只留格子大地图、回合制推进、地形地表与战争迷雾**，主角从"一个文明"变成"一支英雄小队"。

| 项目 | 内容 |
|------|------|
| 探索层 | **全面对标文明**：六边形格子大地图、回合制移动（移动力 + 下一回合）、Civ 式地形/地表双层系统、战争迷雾、POI 兴趣点 |
| 战斗层 | **全面对标 BG3**：遇敌后缩放到局部战场，先攻轮转 + 动作经济 + 地形互动，规则用 D&D 5e 简化版 |
| 成长层 | 4 人小队养成：职业、等级、法术、装备（替代文明的科技/市政树） |
| 相机 | Civ 式正交俯视：缩放（`orthoSize` 插值），45° 步进旋转（M2 后实现）；验证期可略俯仰以便读悬崖/水面 |
| 单局节奏 | 大地图探索 → 触发遭遇 → 缩放进入回合战斗 → 结算/养成 → 继续探索。Demo 单局约 80~120 探索回合 |
| 分发 | 浏览器本地 / 静态托管（GitHub Pages 等）；**不做** TapTap Maker 打包 |

### 设计支柱

1. **探索的文明感**：迷雾、地形、移动力消耗、翻格子的期待感，一个不少。
2. **战斗的博德感**：每一寸地形都是武器——高地、掩体、表面（火/水/油）与法术联动；移动力可自由拆分，打带跑成立。
3. **规则透明**：每一次骰点、命中判定都进战斗日志，玩家可以复盘。
4. **地表可读（网页新增）**：水/林/山等尽量对标 Civ6/7、Humankind、Age of Wonders 的地貌可读性；运行时**纯程序化 Shader**，不用外部模型/贴图（见图形验证文档）。

## 2. 双层尺度架构

文明的一格代表数十公里，D&D 的一格是 1.5 米——两者无法共用同一张格网。采用**英雄无敌式双尺度**：

```
┌─────────────────────────────────────────────┐
│ 探索层（Civ 尺度）                            │
│  六边形大地图（60×40 格）                     │
│  格子 = 一片区域，带基础地形 + 地表特征        │
│  小队以"英雄令牌"在格间移动（回合制）          │
└──────────────┬──────────────────────────────┘
               │ 遇敌 / 进入遭遇格
               ↓ 镜头缩放过渡（orthoSize 插值）
┌─────────────────────────────────────────────┐
│ 战斗层（BG3 尺度）                            │
│  以遭遇点为中心生成局部战场（20×15 格）        │
│  格子 = 1.5 米，地形由遭遇点的 Civ 地形映射   │
│  严格回合制：先攻队列 + 动作经济              │
└─────────────────────────────────────────────┘
```

- **场景共存（同 Scene）**：战场网格挂独立 `BattleRoot`（Babylon `TransformNode`）。进入战斗时隐藏遭遇区域探索格（`setEnabled(false)`），相机 `orthoSize` 插值推近；战斗结束 dispose `BattleRoot`，恢复探索格。战斗期间探索层 HexMap **冻结**。
- **逃跑规则**：先执行"脱离"动作（消耗动作）清除威胁，再退到战场边缘格；下回合在边缘格执行"逃离"，回到探索层。未脱离时，离开敌威胁邻格会触发借机攻击。
- 六边形统一 **pointy-top + 轴坐标**，探索/战斗两层坐标公式一致（仅格距参数不同）。

## 3. 探索层（对标文明）

### 3.1 地形系统（三层结构）

**移动消耗公式**（定稿）：

```
cost = roadOverride ? 1 : max(1, base_cost + feature_extra)
base_cost = max(terrain_base, hill ? 2 : 0)   -- 丘陵只抬下限，不与冻土叠成 4
跨越河流边时额外 +1（道路桥格 +0）
剩余移动力不足 cost 时不能进入（Civ 式，不赊账）
```

**第一层：基础地形**

| 地形 | base | 视距 | 战斗层映射 |
|------|------|------|-----------|
| 平原 | 1 | 2 | 开阔地 |
| 草原 | 1 | 2 | 开阔地，零星掩体 |
| 沙漠 | 1 | 2 | 沙丘高地 + 沙地困难地形 |
| 冻土 | 2 | 2 | 大面积冰面（移动豁免 + 冻结联动） |
| 丘陵（叠加层） | 抬 base 至 ≥2 | 3（登高望远） | 高地：攻击检定 +2 |
| 山脉 | 不可通行 | 阻挡 LOS | 不可进入格 |
| 海洋/海岸/湖泊 | 不可通行 | — | 战场边界深水域（不可通行） |

**第二层：地表特征（叠加）**

| 地表 | extra | 战斗层映射 |
|------|-------|-----------|
| 森林 | +1 | 树木 = 半掩体 AC+2，挡 LOS |
| 雨林 | +1 | 密林 = 四分之三掩体 AC+5，少量毒雾 |
| 沼泽 | +1 | 大面积困难地形 + 毒雾表面 |
| 沙丘 | +1 | 沙漠专属，丘陵效果 |
| 河流（格边） | 跨界 +1 | 贯穿战场的 1~2 格宽浅水带（**可站立、导电**） |
| 道路 | override = 1（最高优先） | 战场上无修正平地走廊 |
| 绿洲 | 0 | 中心清水表面（灭火位） |

**第三层：兴趣点 POI**

宝箱、遗迹、神龛、营地、巢穴、传送门为初版；**城镇商店后移**（需物品经济，M6 视情况）。

### 3.2 回合制探索（定稿数值）

- **小队移动力 = 3 格/回合**（取全队最慢成员；路径全在道路上时 +1）。
- **视距**：基础 2 格；丘陵上 3；身处森林/雨林/沼泽降为 1；山脉完全挡 LOS；神龛瞭望增益临时 +1。
- **"下一回合"按钮语义**：① 结算玩家剩余移动 → ② 敌方巡逻单位移动（**2 格/回合**）→ ③ 视野接触检查 → ④ POI 回合型效果结算。
- **战争迷雾**：未探索黑雾 / 已探索灰雾 / 视野内全亮。
- **节奏验收**：开局前 5 回合揭开 12~18 格；每点 2~3 次"下一回合"至少发生一次"新地形揭开 / POI 进入范围 / 敌影接触"。

### 3.3 相机与输入（网页）

- **相机**：Babylon 正交相机；缩放 = 插值 `orthoSize`；45° 步进旋转（绕地图中心 yaw，**M2 后**）。
- **桌面**：滚轮缩放、左键选中/移动、悬停 tooltip、中键/右键拖拽平移。
- **触屏（P1，网页可后补）**：双指捏合缩放、单指拖平移、点按选格、长按 tooltip、双指点按旋转。
- **拾取**：`scene.pick` / 射线与 y=0 平面求交 → 世界坐标转 hex 轴坐标。

### 3.4 POI 事件

继承 v0.4（每类 2~3 个，检定/分支/奖励写清）：

**宝箱**：生锈铁箱 / 符文封箱 / 诱饵箱（陷阱）。  
**遗迹**：坍塌祭坛 / 回声图书馆 / 镜厅。  
**神龛**：愈合之泉 / 战神石像 / 暗影神龛。  
**营地**：扎营休整（软 CD：全休整后 3 探索回合内不可再全休）/ 警戒露营 / 流浪商人。  
**巢穴**：外围哨站 / 巢核 Boss / 谈判内讧。  
**传送门**：不稳裂隙 / 破损拱门。

（细则与 DC/奖励与 v0.4 相同，实现时写入 `data/poiEvents.ts`。）

## 4. 战斗层（对标 BG3，D&D 5e 简化版）

### 4.1 回合结构

```
先攻阶段：d20 + 敏捷调整值排序（同值 PC 优先；Boss 先攻骰优势）
每个单位回合内：
  移动力：速度 9 米 = 6 格（1 格 1.5 米），可在动作前/中/后自由拆分
  动作 ×1：攻击 / 施法 / 疾走（本回合移动力 +6 格）/ 脱离 / 使用物品 / 协助
  附赠动作 ×1：副手攻击 / 治疗真言类 / 游荡者灵巧动作
  反应 ×1（回合外）：借机攻击 / 护盾术
```

### 4.2 核心判定与状态

- **攻击检定**：d20 + 熟练 + 属性调整值 ≥ AC；出 20 必中且伤害骰翻倍，出 1 必失。
- **豁免**：d20 + 属性调整值 ≥ 法术 DC（8 + 熟练 + 施法属性调整值）。
- **高地**：对低地攻击 **+2 加值**（非优势）。
- **掩体**：半掩体 AC+2 / 四分之三 AC+5。
- **状态表**：隐形、目盲、倒地、束缚、惊惧（幼龙）——同 v0.4。

### 4.3 地形与表面

| 表面 | 规则 |
|------|------|
| 火面 | 回合开始 1d6 火焰；油面被火系伤害点燃（**点燃消耗油面**） |
| 油面 | 敏捷豁免否则倒地；持续 2 回合蒸发 |
| 水面（浅水） | **可站立**；闪电伤害对水面目标 **+50%**，每回合每目标限一次 |
| 深水 | 不可通行边界 |
| 冰面 | 进入/开始时敏捷豁免否则倒地；火系融化成水面 |
| 毒雾 | 回合开始 1d4 毒素，视线半遮挡 |

清除链：水灭火、火融冰成水、冰冻结水面、圣水净化毒雾。敌人带抗性表。

### 4.4 法术点数池与平衡红线

- 点数：`L1:2 … L6:12`；N 环扣 N 点；戏法免费。
- 环阶锁：2 环 ≥3 级，3 环 ≥5 级；每日上限与单场火球级 ≤2 次。
- 加速术削弱：+2 AC、敏豁优势、速度×2，**不给额外攻击动作**。
- **红线**：1 级 vs 2 刀+1 弓哥布林胜率 70~85%；3 级 vs 食人魔 ≥4 轮；幼龙无准备胜率 &lt;40%，有准备 60~75%。

### 4.5 法术表（16 个）

0：火焰箭 / 神圣火焰  
1：魔法飞弹 / 燃烧之手 / 治疗真言 / 护盾术 / 命令术 / 油脂术  
2：灼热射线 / 蛛网术 / 隐形术 / 造水术  
3：火球术 / 闪电束 / 群体治疗真言 / 加速术  

数据驱动 + `SpellEffects` 分发表。

### 4.6 职业与敌人

- **4 职业**：战士、法师、牧师、游荡者；等级 1~6，里程碑升级。
- **敌人 9 种**：哥布林刀/弓、狼、骷髅、兽人、巨蛛、邪教徒、食人魔（精英）、幼龙（Boss）——属性块同 v0.4。
- **遭遇预算 / AI**：同 v0.4（集火、弓手找掩体、施法者保距离）。

### 4.7 战场生成（BattleMapGen）

- 20×15 格；种子 = `mapSeed + q + r + encounterIndex`。
- 配方：开阔/疏林/密林/丘陵/河岸/沼泽/冻原（掩体/高地/表面区间同 v0.4）。
- 算法 8 步 + 连通性修复；M3 可先 3 个手摆模板。

## 6. 技术架构（网页 / Babylon）

### 6.1 模块划分

```
src/
├── main.ts
├── scene/createScene.ts          # 正交相机、光、雾
├── hex/
│   ├── coords.ts                 # 轴坐标 / 邻居 / 距离 / A*（纯函数）
│   ├── HexMap.ts                 # 探索层地形地表 POI
│   ├── mapgen.ts                 # 种子地图
│   └── ChunkMesher.ts            # 8×8 合并 VertexData
├── render/
│   ├── HexTerrainMaterial.ts     # 纯程序化 ShaderMaterial
│   └── shaders/                  # GLSL：噪声 / 水林山冰
├── combat/                       #（玩法里程碑）CombatManager, SpellEffects, …
├── explore/                      # TurnManager, POI, PatrolAI
├── character/                    # Party, classes
├── data/                         # spells, terrains, encounters (TS modules)
└── ui/                           # HUD, ActionBar, CombatLog, debugPanel
```

依赖：`coords` ← `HexMap` / `ChunkMesher` / `BattleMapGen`；探索与战斗互不直接改对方地图对象。

### 6.2 关键选型

| 需求 | 方案 |
|------|------|
| 引擎 | Babylon.js + Vite + TypeScript |
| 大地图渲染 | Chunk 合并网格；**禁止**每格独立 mesh；程序化顶点属性 |
| 地表外观 | **纯 GLSL**（无 jpg/png/glb 采样）；对标见 `docs/VISUAL_TARGETS.md` |
| 迷雾 | 顶点色 / chunk 重建（回合末） |
| 战场 | `BattleRoot` TransformNode；结束 dispose |
| 存档 | `localStorage` / IndexedDB + 版本迁移钩子；战斗开始自动存 |
| 测试 | Vitest：Dice / HexGrid / A* / 战斗结算纯逻辑 |
| 音频 | Web Audio；M6 前基础包 |

### 6.3 明确不做（与图形验证一致）

- 运行时外部贴图/模型装扮地形  
- TapTap Maker / UrhoX / Lua  
- 城市建造、科技树、外交、联机
