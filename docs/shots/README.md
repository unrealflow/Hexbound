# Screenshots

Local validation captures (not runtime assets). Generated via `npm run shots` against a running Vite server (`npm run dev -- --host 127.0.0.1 --port 5188`).

Files:
- `01-overview-default.png` — default seed overview
- `02-zoomed-cliffs.png` — zoomed terraces/cliffs
- `03-panned-coast.png` — panned coastal view
- `04-wide-biomes.png` — wide biome diversity
- `05-reseed-diversity.png` — random reseed

Optional `*-canvas.png` are raw canvas dumps from the capture script.
Art refs remain under `refs/` (see `refs/SOURCES.md`). ShaderToy technique notes: `docs/shadertoy-refs/TECHNIQUES.md`.
